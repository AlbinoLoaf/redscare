# Getting started

## Requirements

- To run the code, you need **Java OpenJDK 21.0.8** installed.
- Data folder without `readme` (deleted in our data folder).
- Data folder without `wall-n-10000` (deleted in our data folder).
- Data folder without `wall-p-10000` (deleted in our data folder).
- Data folder without `wall-z-10000` (deleted in our data folder).

## Running the code

In the root folder, run: `./run`

## Troubleshooting

If the run script does not execute, it might be because it does not have execute privileges.  
To fix this on Linux, run: `chmod +x run`
